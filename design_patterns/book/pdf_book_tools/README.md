# Design Patterns — PDF book tools

Build tooling for the Design Patterns PDF. The finished book lives in [`../pdf/`](../pdf/).

## Build

```bash
cd design_patterns/book/pdf_book_tools
npm install
npm run build
```

Output:

- `../pdf/design_patterns_1_0_0.pdf`
- `out/design-patterns-book.html` (intermediate)

Requires Google Chrome or Microsoft Edge (used by Puppeteer).
