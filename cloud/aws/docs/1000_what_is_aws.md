# 1.1 What is AWS?

**AWS** (Amazon Web Services) is Amazon’s public cloud. It offers on-demand compute, storage, networking, databases, and hundreds of managed services across regions worldwide.

This page is the AWS view of the shared concept **[What is the cloud / cloud model](../../docs/1000_what_is_the_cloud.md)**.

## On this page

- [In plain words](#in-plain-words)
- [How you work with AWS](#how-you-work-with-aws)

## In plain words

With AWS you:

- Create an **account** and sign in to the console (or use the CLI and APIs).
- Pick a **region** close to your users.
- Launch services such as **EC2** (virtual machines), **S3** (object storage), **VPC** (your network), **IAM** (who can do what), and many more.
- Pay mainly for what you use, with options to reserve capacity when usage is steady.

AWS is the same cloud model as Azure and GCP: rent infrastructure and managed services instead of running your own data center. The names and consoles differ.

## How you work with AWS

| Path | What it is for |
|------|----------------|
| AWS Management Console | Browser UI for learning and day-to-day tasks |
| AWS CLI | Scriptable commands from your terminal |
| SDKs / APIs | Application code talking to AWS |
| Infrastructure as Code | CloudFormation, CDK, and similar tools (covered later) |
