# Azure

Microsoft Azure is a public cloud platform: identity (Microsoft Entra ID), compute, storage, networking, databases, and managed services across regions.

These tutorials walk through the building blocks you need most often — identity, networking, compute, storage, data, messaging, and operations — with docs under `docs/`, demos under `code/`, diagrams under `static/`, and helper scripts under `tools/`.
