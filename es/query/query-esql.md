# 🔍 Introduction to ES|QL

**ES|QL** (Elasticsearch Query Language) is a powerful, SQL-inspired language for querying and transforming data in Elasticsearch. It enables structured, readable queries with support for pipes, projections, and expressions—ideal for analytics and observability use cases.
