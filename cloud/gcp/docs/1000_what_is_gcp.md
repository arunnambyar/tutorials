# 1.3 What is Google Cloud?

**GCP** (Google Cloud Platform) is Google’s public cloud. It offers on-demand compute, storage, networking, databases, and managed services, with particular strength in data, analytics, and Kubernetes.

This page is the GCP view of the shared concept **[What is the cloud / cloud model](../../docs/1000_what_is_the_cloud.md)**.

## In plain words

With GCP you:

- Work inside a **project** (the main unit for APIs, billing, and IAM).
- Pick a **region** and **zone** for your resources.
- Create services such as **Compute Engine**, **Cloud Storage**, **VPC**, **IAM** / service accounts, and many more.
- Pay mainly for what you use, with committed use discounts when demand is steady.

GCP uses the same cloud model as AWS and Azure: you rent infrastructure and managed services; Google runs the physical cloud.

## How you work with GCP

| Path | What it is for |
|------|----------------|
| Google Cloud console | Browser UI for learning and operations |
| gcloud CLI | Scriptable commands from your terminal |
| Client libraries / APIs | Application code talking to GCP |
| Infrastructure as Code | Terraform, Deployment Manager, and similar (covered later) |
