# 1.2 What is Azure?

**Azure** is Microsoft’s public cloud. It offers on-demand compute, storage, networking, databases, and managed services, with a strong fit for organizations already using Microsoft identity, Windows, and hybrid setups.

This page is the Azure view of the shared concept **[What is the cloud / cloud model](../../docs/1000_what_is_the_cloud.md)**.

## On this page

- [In plain words](#in-plain-words)
- [How you work with Azure](#how-you-work-with-azure)
- [Where this sits in the syllabus](#where-this-sits-in-the-syllabus)

## In plain words

With Azure you:

- Work under a **subscription** (billing and resource boundary) and often **Microsoft Entra ID** for sign-in.
- Pick a **region** for your resources.
- Create services such as **Virtual Machines**, **Blob Storage**, **Virtual Network (VNet)**, **RBAC** / managed identities, and many more.
- Pay mainly for what you use, with reservations and savings plans when usage is predictable.

Azure follows the same cloud model as AWS and GCP. You rent capacity and managed services; Microsoft runs the underlying data centers.

## How you work with Azure

| Path | What it is for |
|------|----------------|
| Azure portal | Browser UI for learning and operations |
| Azure CLI / PowerShell | Scriptable management from your terminal |
| SDKs / REST APIs | Application code talking to Azure |
| Infrastructure as Code | Bicep, ARM templates, Terraform (covered later) |
